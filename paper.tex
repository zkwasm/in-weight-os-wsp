\begin{abstract}
Adapting pretrained Large Language Models (LLMs) to multiple downstream capabilities---such as surgical safety alignment, structured multi-tool invocation, adaptive System-1/System-2 compute routing, novel domain knowledge injection, and multi-turn dialectical reasoning---currently relies on Supervised Fine-Tuning (SFT), Reinforcement Learning (RLHF/DPO/GRPO), or post-hoc model merging (\texttt{Task Arithmetic}, \texttt{TIES-Merging}). However, gradient-based updates modify dense, overlapping singular subspaces across layers, giving rise to two fundamental pathologies: (1) \textbf{Intra-Task Over-Triggering} (e.g., tool-calling SFT models hallucinate tool invocations on $28\%\text{--}100\%$ of standard mathematical reasoning queries, while safety SFT models falsely refuse $20\%\text{--}100\%$ of benign technical prompts containing sensitive keywords on \texttt{XSTest}); and (2) \textbf{Inter-Task Destructive Interference}, where sequential continual SFT suffers catastrophic forgetting and multi-task weight merging degrades individual skills by $25\%\text{--}66\%$.

In this paper, we introduce \textbf{In-Weight OS}, a gradient-free post-training paradigm that compiles multiple heterogeneous capabilities---spanning behavioral routing, associative domain-knowledge memory, and deep multi-layer verification circuits---into \textbf{strictly disjoint dormant SwiGLU channels} ($\mathcal{C}_1 \cap \mathcal{C}_2 \cap \dots \cap \mathcal{C}_K = \emptyset$). Grounded in terminal-layer KV-cache invariance and \texttt{bfloat16} residual mantissa absorption ($\mathrm{fl}_{\mathrm{bf16}}(h + \Delta h) \equiv h$ for gate pre-activations $z \le -15.0$), we formulate a \textbf{Dual-Gate Conjunctive Hard-Negative Orthogonalization and 2-Fold Out-of-Fold (OOF) Shrinkage Solver} that shapes both $w_{\mathrm{gate}}$ and $w_{\mathrm{up}}$ to eliminate boundary leakage on static code and math problems (\texttt{CRUXEval-O}, \texttt{AMC}, \texttt{MATH-500}). Evaluated across \textbf{2,628 unseen test instances} on \textbf{\texttt{Qwen3-8B}} ($L=36$) and \textbf{\texttt{Meta-Llama-3.1-8B-Instruct}} ($L=32$), In-Weight OS compiles up to five concurrent skills in $12\text{--}25$ seconds with \textbf{zero gradient steps}, achieving $91.4\%\text{--}98.3\%$ multi-skill primary success, $\mathbf{100.0\%}$ novel knowledge recall ($0.0\%$ base), and $\mathbf{0.00\%}$ false tool triggers across $200$ hard math and static Python code boundary problems.
\end{abstract}

\section{Introduction}

Post-training transforms a generalist pretrained LLM into a safe, tool-capable, domain-informed, and compute-efficient assistant. In standard practice, each post-training skill is acquired via gradient descent---either sequentially (Continual SFT / RL) or via separate adapters that are subsequently combined in weight space (\texttt{Task Arithmetic} \cite{ilharco2023}, \texttt{TIES-Merging} \cite{yadav2023}).

Yet gradient-based post-training suffers from a fundamental geometric flaw: stochastic gradient descent lacks an algebraic mechanism to confine parameter updates to a trigger-specific activation manifold. When fine-tuned on $16\text{--}30$ examples of a specialized behavior, rank-unconstrained or LoRA updates shift the global bias of the residual stream:
\begin{enumerate}
    \item \textbf{Exaggerated Safety (\texttt{XSTest} Over-Refusal)}: Safety-tuned models latch onto surface lexical triggers (\texttt{kill}, \texttt{terminate}, \texttt{dump}, \texttt{exploit}, \texttt{crack}), refusing $20\%\text{--}100\%$ of benign systems-programming and mathematical questions.
    \item \textbf{Hallucinated Tool Invocations}: Models fine-tuned on function-calling schemas over-trigger tool calls on $28\%\text{--}100\%$ of pure mathematical derivations (\texttt{AMC}, \texttt{MATH-500}) and static code-comprehension tasks (\texttt{CRUXEval-O}).
    \item \textbf{Multi-Adapter Subspace Collision}: When combining a Safety adapter ($\Delta W_{\mathrm{safe}}$), a Tool-Calling adapter ($\Delta W_{\mathrm{tool}}$), and a Fast-Routing adapter ($\Delta W_{\mathrm{fast}}$), parameter-space heuristics (\texttt{Task Arithmetic}, \texttt{TIES-Merging}) cannot prevent activation-space cross-talk.
\end{enumerate}

We resolve both pathologies by treating dormant SwiGLU channels of the Transformer as a **multi-tenant, channel-partitioned operating system (\emph{In-Weight OS})**.

\section{Theory: Dual-Gate Conjunctive Superposition}

Let $\mathrm{MLP}_{l}(x) = \sum_{c=1}^{d_{\mathrm{ffn}}} w_{\mathrm{down}, c} \, \sigma(\langle w_{\mathrm{gate}, c}, x \rangle) \langle w_{\mathrm{up}, c}, x \rangle$ denote a gated MLP layer. Suppose we wish to install $K$ distinct post-training skills $\mathcal{S}_1, \dots, \mathcal{S}_K$, where each skill $m$ is defined by an active state manifold $\mathcal{X}_+^{(m)} \subset \mathbb{R}^{d_{\mathrm{model}}}$ and a protected boundary manifold $\mathcal{X}_{\mathrm{guard}}^{(m)}$ (including hard-negative boundary examples such as static Python code comprehension in \texttt{CRUXEval-O}).

\begin{theorem}[Zero-Interference Multi-Skill Superposition]
\label{thm:superposition}
Suppose $K$ skills are compiled into pairwise disjoint dormant channel subsets $\mathcal{C}_1, \dots, \mathcal{C}_K \subset \mathcal{D}_{L-1}$ ($\mathcal{C}_m \cap \mathcal{C}_{m'} = \emptyset$ for all $m \ne m'$). If for every skill $m$ and channel $c \in \mathcal{C}_m$, the gate vector $w_{\mathrm{gate},c}$ satisfies:
\begin{equation}
\langle w_{\mathrm{gate},c}, x \rangle \le -15.0 \quad \forall x \in \mathcal{X}_{\mathrm{general}} \cup \bigcup_{m' \ne m} \mathcal{X}_+^{(m')},
\end{equation}
then under IEEE 754 \texttt{bfloat16} residual addition, for any input $x \in \mathcal{X}_+^{(m^*)}$ belonging to skill $m^*$, all channels $c \in \bigcup_{m' \ne m^*} \mathcal{C}_{m'}$ are absorbed bit-for-bit into the residual stream ($\mathrm{fl}_{\mathrm{bf16}}(h^{(L-1)} + \Delta h_c) \equiv h^{(L-1)}$), and the superposed model executes skill $m^*$ identically to a single-skill model.
\end{theorem}

\subsection{Dual-Gate Hard-Negative Orthogonalization \& 2-Fold OOF Calibration}
To prevent boundary leakage when general math or static code problems (e.g., \texttt{CRUXEval-O} prompts containing \texttt{def f(x):}) share lexical tokens with tool-execution requests (\texttt{python\_exec}), we exploit \emph{both} multiplicative factors of SwiGLU ($\sigma(\langle w_{\mathrm{gate}}, x \rangle)$ and $\langle w_{\mathrm{up}}, x \rangle$):
\begin{enumerate}
    \item \textbf{High-Shrinkage Boundary-Guarded Readout}: Given positive states $X_+$, semantic negatives $X_{\mathrm{neg,sem}}$, mid-FSM negatives $X_{\mathrm{neg,fsm}}$, and hard-negative boundary guards $X_{\mathrm{guard}}$ (containing both mathematical proofs and static code comprehension problems), we solve:
    \begin{equation}
    \begin{aligned}
    R &= (1-\lambda_s) X_p^\top X_p + \lambda_g \tilde{\alpha}_g X_{\mathrm{guard}}^\top X_{\mathrm{guard}} + \lambda_s \bar{c} I, \\
    k &= \operatorname{normalize}\big(R^{-1} X_p^\top y\big).
    \end{aligned}
    \end{equation}
    \item \textbf{Dual-Gate Conjunctive Up-Projection}: Let $d_+ = \operatorname{normalize}(\mu_+)$ and $b_{\mathrm{base}} = d_+ / \mathbb{E}_{X_+}[\langle d_+, x \rangle]$. We orthogonalize $k$ against $d_+$ ($k_\perp = \operatorname{normalize}(k - \langle k, d_+ \rangle d_+)$) and set:
    \begin{equation}
    w_{\mathrm{up},c} = b_{\mathrm{base}} + \frac{0.35 \, k_\perp}{\mathbb{E}_{X_+}[\langle d_+, x \rangle]},
    \end{equation}
    amplifying $\langle w_{\mathrm{up},c}, x \rangle$ on true positives while suppressing it toward zero on boundary hard-negatives.
    \item \textbf{2-Fold Out-of-Fold (OOF) Threshold Placement}: Estimating the finite-sample shrinkage factor $\rho = \mathbb{E}[\mathrm{oof}_+] / \mathbb{E}[\mathrm{in}_+]$ via 2-fold cross-validation on $X_+$, we set:
    \begin{equation}
    \begin{aligned}
    p_{\mathrm{low}} &= \rho \cdot Q_{0.06}(\mathrm{in}_+), \quad \theta = 0.52 n_{\max} + 0.48 p_{\mathrm{low}}, \\
    s &= 17.5 / (p_{\mathrm{low}} - \theta), \quad w_{\mathrm{gate},c} = s(k - \theta b_{\mathrm{base}}).
    \end{aligned}
    \end{equation}
\end{enumerate}

\section{Experiments: Scaling to Heterogeneous Skills \& 2,628 Unseen Instances}

To address whether In-Weight OS extends beyond routing switches to **non-routing knowledge injection** and **hard boundary robustness**, we evaluate across a $10\times$ expanded benchmark ($660$ unseen single-turn instances + $654$ 3-turn dialectical dialogues = $1,314$ unseen instances per model):
\begin{enumerate}
    \item \textbf{Zero Boundary Leakage on \texttt{CRUXEval-O} Static Code \& \texttt{AMC}/\texttt{MATH} (Table~\ref{tab:scaling_os})}: In v1.0, calibrating only on math problems left a $10.0\%$ false tool-call rate on \texttt{Llama-3.1-8B} when encountering static Python code comprehension problems (\texttt{CRUXEval-O}). By incorporating Dual-Gate Conjunctive Orthogonalization with balanced math and static code boundary guards, false tool calls drop to \textbf{$\mathbf{0.0\%}$ ($0/120$ on math and $0/80$ on \texttt{CRUXEval-O} static Python code)} on both \texttt{Llama-3.1-8B} and \texttt{Qwen3-8B}, while unseen tool routing reaches $99.2\%\text{--}100.0\%$ ($N=120$).
    \item \textbf{Injecting Novel Domain Knowledge \& Symbolic Operators (Skill 4, $N=60$)}: We compile three novel domain facts and algebraic rules absent from pretraining ($0.0\%$ base accuracy) into $58$ dormant channels ($\mathcal{C}_4$): (i) \emph{Arkreen-v4 protocol parameters} ($72\%$ BFT quorum, $18$s epoch), (ii) \emph{the custom Zenith-Nabla algebraic operator} ($a \nabla b = 4a - 3b + 9$), and (iii) \emph{Helios-9 kernel fault \texttt{ERR-HX-Alpha} diagnostics}. Across $60$ unseen paraphrased test queries, both \texttt{Qwen3-8B} and \texttt{Llama-3.1-8B} achieve \textbf{$\mathbf{100.0\%}$ ($60/60$) exact knowledge recall} without degrading Skills 1--3.
    \item \textbf{Coexistence with Deep Multi-Layer Dialectical Circuits (Skill 5, $N=654$)}: Because Skills 1--4 occupy only $109$ channels of $\mathrm{MLP}_{L-1}$ ($0.76\%$ of a single layer), they compose orthogonally with our multi-layer Dialectical Verification Circuit in layers $[0.66L, 0.84L]$ and disjoint $\mathrm{MLP}_{L-1}$ channels $[200:238]$.
\end{enumerate}

\subsection{Beyond Routing: Premise-Recall + Stem-Release for Multi-Hop Math \& Dynamic Tool Generation}
A critical question is whether dormant-channel compilation is restricted to static string switches, or can empower \emph{open-ended multi-hop mathematical calculation} and \emph{dynamic argument generation}. We achieve this via \textbf{In-Weight Premise-Recall + Stem-Release} (Table~\ref{tab:v3_multihop}):
\begin{itemize}
    \item \textbf{Multi-Hop Numerical Reasoning over Injected Rules ($N=60$)}: Dormant channels in $\mathcal{C}_{\mathrm{know}}$ emit a compact axiom header (e.g., \texttt{Recall\_Rule: [Zenith Nabla maps a,b to four*a minus triple*b plus nine]. Step=}) and immediately place all subsequent generation states in $\mathcal{X}_-$ ($z \le -15.0$). Control returns seamlessly to the base model's native reasoning circuits, which substitute the user's unseen numbers $(a,b,c)$ and compute multi-step derivations (e.g., \emph{``Zenith Nabla(9, 2) = 4*9 - 3*2 + 9 = 39. Step 2: 39 + (-4) = 35. \_final\_answer\_: (35)''}), raising unseen multi-hop numerical accuracy from $0.0\%$ to $\mathbf{93.3\%}$ ($56/60$) on \texttt{Qwen3-8B}.
    \item \textbf{Dynamic Tool Argument Generation ($N=30$)}: Rather than emitting a fixed JSON string, $\mathcal{C}_{\mathrm{tool}}$ emits only the schema prefix \texttt{\{"tool":"sql\_engine","stmt": "SELECT} and releases control ($z \le -15.0$), allowing the base model to dynamically synthesize task-specific SQL queries (e.g., \texttt{SELECT email, COUNT(*) FROM newsletter\_subscribers GROUP BY email HAVING COUNT(*) > 1;}) with $\mathbf{90.0\%}$ argument grounding accuracy and $\mathbf{0.0\%}$ false triggers on \texttt{CRUXEval-O}.
\end{itemize}

\section{Conclusion}
By partitioning dormant SwiGLU neurons into orthogonal, dual-gate boundary-guarded banks, \textbf{In-Weight OS} unifies behavioral routing, associative knowledge injection, and deep reasoning circuits into a zero-gradient post-training framework that eliminates catastrophic forgetting and model-merging interference.
